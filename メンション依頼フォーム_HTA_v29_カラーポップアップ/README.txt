メンション依頼フォーム HTA - カラー版 横幅再調整 v22
================================================

■ 今回の調整

・v21で広げすぎた横幅をv20ベースへ戻して再調整
・依頼3の取消ボタンがタイプ欄内に入り込んでいた構造を修正
・各入力欄は横幅を少しだけ拡大
・メールメモ / 処理日時 / 期日をdetail-zoneいっぱいに再配分
・タイプ欄もdetail-zoneいっぱいまで拡大
・オプション欄の余白を整理

■ ボタン右端の整列

「2件目を入力」
「3件目を入力」
「× この依頼を取り消す」

は、タイプ欄＋オプション欄の右端ラインに揃うよう調整。
送信ボタンもカード内の入力エリア右端に近い位置へ揃えています。

■ 入力しやすさ

・入力欄高さ 46px
・追加/取消ボタン 230×44px
・送信ボタン 190×60px
・拠点 / 依頼者欄も少し拡大

■ 維持仕様

・依頼2取消時、依頼3があれば依頼2へ繰り上げ
・取消確認ポップアップ
・依頼別カラーポップアップ
・必須入力チェック
・時短/至急：●/空欄
・チラつき軽減
・CSV排他制御

■ CSV試作保存先
%TEMP%\MentionRequestCSV


[v23]
- ボタン配置をユーザーのイメージに合わせて再調整
- 依頼1: 2件目ボタンは右側スロットに配置
- 依頼2: 3件目ボタン + 取消ボタンを右寄せの2連配置
- 依頼3: 取消ボタンは同じ右側スロットに配置
- 行幅を 807px → 730px に見直し、右側がキツキツにならないよう調整
- ボタン間隔を少し拡大
- ボタン幅をわずかに拡大


[v24]
- ボタンの右端を、タイプ欄の右端ラインに揃えるよう再調整
- 依頼1の「2件目を入力」、依頼2の「3件目を入力」「×この依頼を取り消す」、依頼3の取消ボタンの右端位置を統一
- .add-row / .action-row / .action-row-cancel-only の幅を 730px → 630px に見直し
- ボタン同士の余白を微調整


[v25 横幅安定化]
- ボタン位置の基準を「タイプ欄の右端」に統一
- type-area / add-row / action-row / cancel-only をすべて625pxで統一
- 2件目ボタン、3件目+取消、依頼3取消の最後尾が同じ縦ラインに揃う
- 固定座標や過剰な横幅拡張をやめ、text-align:rightで自然に整列
- HTA互換性を考慮しflexは使用せず、inline-blockで配置
- ボタン幅230px、2ボタン間隔18px


[v26 自動画面フィット]
- カラー版へモニター解像度・Windows表示領域に応じた自動倍率調整を追加
- 24インチFHD相当では約92%を上限目安として少し縮小
- 2560px以上の広い表示領域では最大100%
- 依頼1 / 2 / 3 の表示数に応じて高さも再計算
- 依頼追加・取消・送信後リセット時に再フィット
- 従来の固定最小倍率 0.78 を廃止
- 画面端に上下左右の余白を確保
- ボタン右端揃え・横幅安定化v25のレイアウトは維持


[v27 ファイル名文字化け修正]
- HTA本体のファイル名を「メンション依頼フォーム.hta」に修正
- HTML/JS/CSSの中身・自動画面フィット等の機能はv26から変更なし
- ZIP内の日本語ファイル名をPython側でUTF-8として明示的に再作成


[v28 解像度追従・自動フィット再調整]
- カラー版のみ更新
- 1920×1080で縮みすぎていたv26/v27の自動倍率を見直し
- FHD級では約96%を目安にし、以前より少し大きく表示
- 画面に収まらない場合は横幅・高さから自動的に縮小
- HTA起動中に解像度、Windows表示倍率、接続モニターが変わった場合も0.5秒周期で検知し再フィット
- 依頼1/2/3の追加・取消時の自動再調整は継続
- v25のボタン右端揃え・横幅安定化レイアウトを維持


[v29 必須入力アラート順変更]
入力確認の優先順を以下へ変更：
1. 組織
2. CA名
3. 代理CA組織
4. 代理CA名
5. メールメモ
6. 処理日時
7. タイプ
8. 拠点

※「組織＋CA名」または「代理CA組織＋代理CA名」のどちらか一式必須、
という従来の入力ルール自体は変更していません。
※拠点チェックは送信時の最後へ移動しました。
※依頼追加時は従来どおり、追加前の依頼カードだけをチェックします。
